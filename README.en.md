# Animated UI Libraries

🇧🇷 [Leia em português](README.md)

Three component libraries to bring modern interfaces to life, each with a different approach.

---

## [Originkit](https://www.originkit.dev/)

![Originkit](assets/originkit.png)

A library focused on animated components for modern websites.

Its key differentiator is flexibility: you can copy the code, use it directly in Framer, install it via CLI, or integrate it through MCP with tools like Claude Code, ChatGPT, Lovable and Cursor. It's the option most aligned with the idea of vibecoding with AI.

---

## [Skiper UI](https://skiper-ui.com/)

![Skiper UI](assets/skiper-ui.png)

Brings less common, more experimental components to projects built with Next.js and shadcn/ui.

It stands out for sophisticated interactions, hover effects, transitions, interfaces inspired by well-known products, and components that steer away from the generic SaaS look.

---

## [Cult UI](https://www.cult-ui.com/)

![Cult UI](assets/cult-ui.png)

Works as an expansion of the shadcn/ui ecosystem, offering animated components, effects, widgets, blocks and patterns for modern interfaces.

Since components are added to your project as source code, you can modify everything and fold them into your own design system, without being locked into a closed dependency.
